# OpenCob

OpenCob is an AI-powered VS Code extension for COBOL analysis, refactoring, and modernization. It provides an agentic chat interface that can read, write, and reason about code autonomously.

## Key Features

- **Agentic Chat** — multi-turn conversations with tool use (read/write files, search, run commands)
- **Orchestrator Mode** — decomposes complex tasks into subtask plans and executes them
- **Customizable Instructions** — scope project rules to file patterns, teams, and lifecycle events
- **Multiple LLM Backends** — OpenAI, Anthropic, Azure OpenAI, Ollama, OpenRouter
- **MCP Integration** — connect external tool servers via Model Context Protocol
- **Inline Editing** — Cmd/Ctrl+I for quick edits in the editor
- **COBOL-Specific Tools** — copybook resolution, paragraph analysis, data division parsing
