# Security Policy

## Supported Versions

The OpenCob maintainers provide security updates for the latest release on the
`main` branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report vulnerabilities privately by email:

- security@opencob.dev

Include as much detail as possible:

- Affected package and version
- Reproduction steps or proof of concept
- Impact assessment
- Suggested remediation (if known)

## Response SLA

- Initial acknowledgement: within 72 hours
- Triage and severity classification: within 7 business days
- Patch timeline: based on severity and exploitability

## Disclosure Process

1. We acknowledge receipt and begin triage.
2. We validate and classify severity.
3. We prepare and test a fix.
4. We coordinate disclosure and release notes.
5. We publish advisory details after a fix is available.
