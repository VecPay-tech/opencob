# OpenCob

Open-Source AI Coding Assistant for VS Code � Privacy-First, Legacy-Ready.

## Features

- AI-powered chat for COBOL, RPG, PL/I legacy code
- Inline code completion (FIM) via local Ollama models
- Privacy-first: all data stays on your machine
- Cross-platform: Windows, Linux, macOS
- Configurable models, modes, and approval workflows

## Installation

1. Install from VSIX: Extensions > ... > Install from VSIX
2. Ensure Ollama is running locally (default: http://127.0.0.1:11434)
3. Pull a model: `ollama pull qwen2.5-coder:7b`

## Configuration

All settings are available under `OpenCob.*` in VS Code Settings.
